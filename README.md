## *Разработка системы для управления рецептами*
Это консольное приложение, которое позволяет создавать блюда, добавлять их в "рецепты", маштабировать порции и генерировать список покупок.

## Установка
Для того, чтобы развернуть проект введите следующие команды в терминале:

```Bash
git clone https://github.com/nnovitskaya/HW2.git
cd HW2
pip install -r requirements.txt```

## Использование
Для проверки работоспособности кода с помощью тестов перейдите в папку с проектом и введите в терминал:

```Bash
pytest```

Для самостоятельного запуска кода вы можете импортировать классы в свой скрипт и запустить программу, например:

```Python
from system_recipes import Ingredient, Recipe, ShoppingList

ingredients = [Ingredient("Мука", 500.0, "г"), Ingredient("Картошка", 300.0, "г"), Ingredient("Яйца", 2, "шт")]
recipe = Recipe("Пирожки с картошкой", ingredients)


shopping_list = ShoppingList()
shopping_list.add_recipe(recipe, 5)

print(shopping_list.get_list())```
